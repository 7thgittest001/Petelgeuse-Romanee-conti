## Persona 1: 田中 健太（Kenta Tanaka）

### 基本情報
- **年齢**: 28歳
- **職業**: IT企業のWebエンジニア
- **居住地**: 東京都中野区（一人暮らし）
- **テクノロジー利用**: iPhone 15 Pro、MacBook Pro、Chrome常用。新しいWebサービスは積極的に試す

### 一日のスケジュール
| 時間 | 行動 |
|---|---|
| 8:00 | 起床（ギリギリ） |
| 9:30 | 出社（リモート週3日） |
| 12:00 | デスクでコンビニ弁当 |
| 19:00 | 退勤 |
| 19:30 | 帰宅、ソファでスマホ |
| 20:00 | YouTube/Netflix |
| 24:00 | 就寝 |

### 行動パターン
- 健康診断で「運動不足」を指摘されて以来、ランニングシューズを買ったが3回しか使っていない
- SNSで友人のランニング記録を見るたびに焦るが、行動には移さない
- 「明日から走ろう」が口癖。明日は永遠に来ない
- ゲーム的な要素があるアプリには反応しやすい

### フラストレーション
- 「走らなきゃ」という罪悪感が常にある
- 実際に外に出るのが面倒（着替え、天気、時間帯）
- フィットネスアプリの通知が「今日はサボりましたね」と責めてくるのがストレス

### ゴール
- 罪悪感なく過ごしたい
- 「自分も何かやっている」という感覚が欲しい
- 楽しみながら（実際には何もせず）健康的な気分になりたい

### 引用セリフ
> 「走りたい気持ちはあるんだよ。気持ちだけは。」
> 「このアプリ、俺のことわかってるな…（ソファから動かずに）」

## Persona 4: 中村 翔太（Shota Nakamura）

### 基本情報
- **年齢**: 35歳
- **職業**: IT企業の営業マネージャー
- **居住地**: 東京都港区（妻と二人暮らし）
- **テクノロジー利用**: iPhone、iPad。業務でSalesforce等を使用。アプリは実用性重視で選ぶ

### 一日のスケジュール
| 時間 | 行動 |
|---|---|
| 7:00 | 起床 |
| 8:30 | 出社 |
| 12:00 | クライアントとランチ |
| 13:00 | 商談・会議 |
| 19:00 | 退勤（週3で接待・飲み会） |
| 22:00 | 帰宅（飲み会の日は24時） |
| 23:00 | シャワー、就寝 |
| (翌朝) | 二日酔いで後悔 |

### 行動パターン
- 営業職のため接待・飲み会が多く、週3〜4回は外食
- 30代に入ってから明らかに体型が変わり、スーツがきつくなった
- 妻に「最近太った？」と言われるのがストレス
- 飲み会の翌朝に「今日こそ走ろう」と思うが、二日酔いで断念するのがパターン
- 「飲んだ分走れば帳消し」という都合の良い理論を信じたい

### フラストレーション
- 接待を断れない立場（断ると売上に影響）
- 飲み会後の罪悪感が翌朝まで残る
- 妻から「また飲んできたの？」と言われるプレッシャー
- ジムに通う時間が物理的にない

### ゴール
- 飲み会の翌朝に「走った」という事実（虚構）で罪悪感を帳消しにしたい
- 妻に「朝走ってきた」と報告したい（嘘だけど）
- 「飲んだカロリー分は走って消費した」と自分を納得させたい

### 引用セリフ
> 「昨日の飲み会、ビール5杯で約1000kcal。今朝15km走ったから帳消し（走ってない）。」
> 「妻に『最近朝ランしてる』って言ったら褒められた。このアプリのおかげ（走ってない）。」

## Persona 5: 高橋 リナ（Rina Takahashi）

### 基本情報
- **年齢**: 22歳
- **職業**: 大学4年生・インフルエンサー志望（フォロワー3,000人）
- **居住地**: 東京都渋谷区（実家暮らし）
- **テクノロジー利用**: iPhone 15、AirPods常時装着。Instagram、TikTok、X（旧Twitter）を毎日更新。トレンドに敏感

### 一日のスケジュール
| 時間 | 行動 |
|---|---|
| 9:00 | 起床、SNSチェック |
| 10:00 | 大学（週3日） |
| 12:00 | カフェでランチ＆撮影 |
| 14:00 | 授業 or カフェで作業 |
| 17:00 | コンテンツ撮影・編集 |
| 20:00 | 夕食 |
| 21:00 | SNS投稿・エンゲージメント確認 |
| 24:00 | TikTok巡回、就寝 |

### 行動パターン
- 常に「バズるネタ」を探している
- 面白いアプリを見つけたら即レビュー動画を撮る
- 「〇〇やってみた」系のコンテンツが得意
- 健康・美容系のコンテンツも発信しているが、実際の運動は苦手
- フォロワーに「リナちゃんも走ってるんだ！」と思わせたい

### フラストレーション
- 健康系インフルエンサーに憧れるが、実際に運動するのは面倒
- 「走ってます」と言いたいが嘘はつきたくない（→ このアプリなら「走った風」なのでセーフ？）
- コンテンツのネタが枯渇しがち
- フォロワー数が伸び悩んでいる

### ゴール
- このアプリを使った面白いコンテンツでバズりたい
- 「走った風になるアプリ」のレビュー動画で新規フォロワーを獲得したい
- 自虐ネタとして「今日も走った（風）」を定期コンテンツ化したい
- 将来的にはアプリとのコラボ案件を狙いたい

### 引用セリフ
> 「みんな〜！このアプリやばいの見つけた！走らないランニングアプリ！笑」
> 「今月の走行距離100km達成しました〜✨（全部バーチャル）#走った風 #人をダメにするアプリ」
