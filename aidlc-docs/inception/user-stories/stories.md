## MVP Stories (Phase 1)

---

### US-001: スタート地点の指定

**As a** 運動不足を自覚しているユーザー  
**I want to** 地図上でスタート地点をタップ/クリックして指定したい  
**So that** 「今日はここから走ろう」と気軽にランニングを始められる（始めた気になれる）

**Priority**: Must Have (MVP)  
**Personas**: 田中健太、佐藤美咲、山田大輔（全員）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: アプリのトップ画面が表示されている  
   When: ユーザーが地図上の任意の地点をクリック/タップする  
   Then: その地点にスタートマーカーが表示される

2. Given: スタートマーカーが設置されている  
   When: ユーザーが別の地点をクリック/タップする  
   Then: スタートマーカーが新しい地点に移動する

**Supplementary Checklist:**
- ✓ 地図は日本全国（将来的には世界）を表示可能
- ✓ 住所検索またはキーワード検索でも地点指定可能
- ✓ 現在地ボタンでGPS位置をスタート地点に設定可能
- ✓ マーカーにはスタート地点であることが視覚的に分かるアイコンを使用

---

### US-002: ゴール地点の指定

**As a** バーチャルランニングを体験したいユーザー  
**I want to** スタート地点とは別にゴール地点を地図上で指定したい  
**So that** 「どこまで走るか」を決めて走った風の体験を開始できる

**Priority**: Must Have (MVP)  
**Personas**: 田中健太、佐藤美咲、山田大輔（全員）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: スタート地点が設定されている  
   When: ユーザーがゴール地点を地図上で指定する  
   Then: ゴールマーカーが表示され、2地点間のルートが自動計算される

2. Given: スタートとゴールが設定されている  
   When: ルート計算が完了する  
   Then: 推定距離と推定所要時間が表示される

**Supplementary Checklist:**
- ✓ ゴール地点も住所検索/キーワード検索で指定可能
- ✓ ルートが存在しない場合（海上など）はエラーメッセージを表示
- ✓ Street Viewのカバレッジがない区間がある場合は警告を表示
- ✓ ゴールマーカーはスタートマーカーと視覚的に区別できる

---

### US-003: ルートの確認

**As a** コースを選んだユーザー  
**I want to** 走る予定のルートを地図上で事前に確認したい  
**So that** 「このコースを走る（風）」というイメージを持ってから開始できる

**Priority**: Must Have (MVP)  
**Personas**: 田中健太、佐藤美咲、山田大輔（全員）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: スタートとゴールが設定されルートが計算されている  
   When: ルート計算が完了する  
   Then: 地図上にルートがライン表示される

2. Given: ルートが表示されている  
   When: ユーザーが「走る」ボタンを押す  
   Then: バーチャルランニング体験が開始される

**Supplementary Checklist:**
- ✓ ルートの総距離が表示される
- ✓ 推定ランニング時間が表示される（ペース: 6分/km想定）
- ✓ ルートを変更したい場合はスタート/ゴールを再設定できる

---

### US-004: バーチャルランニングの開始

**As a** コースを決めたユーザー  
**I want to** 「走る」ボタンを押してバーチャルランニングを開始したい  
**So that** ソファに座ったまま走り始めた気分になれる

**Priority**: Must Have (MVP)  
**Personas**: 田中健太（平日夜）、佐藤美咲（通勤中）、山田大輔（深夜）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: ルートが確定している  
   When: ユーザーが「走る」ボタンを押す  
   Then: スタート地点のStreet View画像が表示され、ランニング体験が始まる

2. Given: ランニングが開始された  
   When: 最初の画像が表示される  
   Then: 距離カウンター（0.0km）、カロリーカウンター（0kcal）、時間カウンター（00:00）が表示される

**Supplementary Checklist:**
- ✓ 開始時に共犯者トーンのメッセージが表示される（例：「さあ、走りましょう（走りませんが）」）
- ✓ ローディング中は「コースを準備中...」等の表示
- ✓ Street View画像が取得できない場合のフォールバック処理

---

### US-005: 走行中の体験

**As a** バーチャルランニング中のユーザー  
**I want to** Street Viewの画像が連続的に切り替わり、走っている感覚を得たい  
**So that** 実際に走っているかのような没入感を（ソファの上で）味わえる

**Priority**: Must Have (MVP)  
**Personas**: 田中健太、佐藤美咲、山田大輔（全員）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: バーチャルランニングが進行中  
   When: 時間が経過する  
   Then: ルートに沿ってStreet View画像が順次切り替わる

2. Given: 画像が切り替わる  
   When: 次の画像に遷移する  
   Then: スムーズなトランジション効果で自然な移動感を演出する

3. Given: ランニング中  
   When: ユーザーが一時停止ボタンを押す  
   Then: ランニングが一時停止し、再開ボタンが表示される

**Supplementary Checklist:**
- ✓ 画像切り替え速度はランニングペース（約6分/km）に相当する間隔
- ✓ 画像間のトランジションがカクつかない（フェード or スライド）
- ✓ 一時停止・再開が可能
- ✓ 途中終了（リタイア）も可能
- ✓ 走行中に距離・カロリー・時間カウンターがリアルタイム更新される

---

### US-006: 現在位置のリアルタイム表示

**As a** バーチャルランニング中のユーザー  
**I want to** 今ルート上のどこを走っているかを地図で確認したい  
**So that** 「今ここを通過している」というリアルタイム感で没入感が高まる

**Priority**: Must Have (MVP)  
**Personas**: 田中健太、佐藤美咲、山田大輔（全員）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: バーチャルランニングが進行中  
   When: Street View画像が切り替わる  
   Then: ミニマップ上の現在位置マーカーが対応する地点に移動する

2. Given: ミニマップが表示されている  
   When: ユーザーがミニマップをタップ/クリックする  
   Then: ミニマップが拡大表示される（またはフルマップに切り替わる）

**Supplementary Checklist:**
- ✓ ミニマップはStreet View表示を邪魔しないサイズ・位置に配置
- ✓ 現在位置マーカーはルートライン上を移動する
- ✓ 走行済み区間と未走行区間が色分けされる
- ✓ 残り距離が視覚的に把握できる

---

### US-007: 走行距離カウンター

**As a** 罪悪感を解消したいユーザー  
**I want to** 走行距離がリアルタイムで増えていくのを見たい  
**So that** 「今日はXkm走った」という達成感（偽り）を得られる

**Priority**: Must Have (MVP)  
**Personas**: 田中健太（罪悪感解消）、佐藤美咲（記録として）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: バーチャルランニングが進行中  
   When: ルート上を進む  
   Then: 走行距離カウンターが0.1km単位でリアルタイム更新される

2. Given: ランニングが完了した  
   When: ゴールに到達する  
   Then: 最終走行距離が確定表示される

**Supplementary Checklist:**
- ✓ 距離はkm単位で小数点第1位まで表示
- ✓ カウンターの数字が増える際にアニメーション効果あり
- ✓ 距離はルート計算に基づく正確な値（直線距離ではない）

---

### US-008: 消費カロリー表示

**As a** ダイエットを気にしているユーザー  
**I want to** 推定消費カロリーがリアルタイムで表示されるのを見たい  
**So that** 「カロリーを消費した」という錯覚で罪悪感が解消される

**Priority**: Must Have (MVP)  
**Personas**: 佐藤美咲（ダイエット意識）、田中健太（罪悪感解消）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: バーチャルランニングが進行中  
   When: 走行距離が増加する  
   Then: 推定消費カロリーがリアルタイムで更新される

2. Given: ランニングが完了した  
   When: ゴールに到達する  
   Then: 最終消費カロリーが確定表示される

**Supplementary Checklist:**
- ✓ カロリー計算は一般的なランニングの消費カロリー基準（体重60kg想定で約60kcal/km）
- ✓ kcal単位で整数表示
- ✓ 「（理論値）」等のユーモラスな注釈を添える
- ✓ カウンターの数字が増える際にアニメーション効果あり

---

### US-009: 完走時の演出

**As a** ゴールに到達したユーザー  
**I want to** 完走した瞬間に達成感を感じる演出を見たい  
**So that** 「今日も走りきった」という満足感（虚構）で一日を終えられる

**Priority**: Must Have (MVP)  
**Personas**: 田中健太、佐藤美咲、山田大輔（全員）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: バーチャルランニングが進行中  
   When: ゴール地点に到達する  
   Then: 完走画面が表示され、最終結果（距離・カロリー・時間）がまとめて表示される

2. Given: 完走画面が表示されている  
   When: 結果が表示される  
   Then: 共犯者トーンの称賛メッセージが表示される

**Supplementary Checklist:**
- ✓ 完走時に視覚的な演出（紙吹雪、光のエフェクトなど）
- ✓ 称賛メッセージは共犯者トーン（例：「お疲れさまでした！今日も立派に走りました（走ってない）」）
- ✓ 結果サマリー：走行距離、消費カロリー、走行時間を一覧表示
- ✓ 「もう一本走る」ボタンで新しいコースを開始可能
- ✓ トップ画面に戻るボタン

---

### US-010: 共犯者トーンのメッセージ体験

**As a** 真面目なフィットネスアプリに疲れたユーザー  
**I want to** アプリが「一緒にサボる共犯者」として語りかけてくれる体験をしたい  
**So that** 罪悪感なく楽しみながらアプリを使い続けられる

**Priority**: Must Have (MVP)  
**Personas**: 田中健太（共感）、山田大輔（ネタとして）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: アプリを起動した  
   When: トップ画面が表示される  
   Then: 共犯者トーンの挨拶メッセージが表示される（例：「おかえりなさい。今日もどこかへ走りに行きますか？（行きませんが）」）

2. Given: バーチャルランニング中  
   When: 一定距離を走行するたびに  
   Then: 走行中の共犯者コメントが表示される（例：「いい調子です！（ソファの上で）」）

**Supplementary Checklist:**
- ✓ メッセージはランダムに複数パターンから選択される
- ✓ トーンは自虐的・シニカル・過剰称賛のいずれか
- ✓ ユーザーを責める・説教するメッセージは絶対に含まない
- ✓ メッセージは体験を邪魔しない控えめな表示（トースト通知等）

---

### US-011: 過剰な称賛演出

**As a** 何もしていないのに褒められたいユーザー  
**I want to** 実際には走っていないのにアプリが大げさに褒めてくれる体験をしたい  
**So that** 「やった感」が最大化され、明日もアプリを開きたくなる

**Priority**: Must Have (MVP)  
**Personas**: 佐藤美咲（SNS共有ネタ）、田中健太（達成感）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: ランニングが完了した  
   When: 完走画面が表示される  
   Then: 過剰な称賛メッセージが表示される（例：「素晴らしい！あなたは今日もアスリートです（ソファの上の）」）

2. Given: 累積走行距離がマイルストーンに到達した（10km, 42.195km, 100km等）  
   When: マイルストーン達成時  
   Then: 特別な称賛メッセージと演出が表示される

**Supplementary Checklist:**
- ✓ 称賛のレベルは走行距離に応じてエスカレートする
- ✓ マイルストーン達成時は通常より派手な演出
- ✓ 括弧書きで現実を突きつけるユーモア（例：「（理論値）」「（走ってない）」）
- ✓ 称賛メッセージは毎回異なるパターン（飽きさせない）

## Phase 2 Stories

---

### US-012: 動画ファイルのダウンロード

**As a** 走った記録を残したいユーザー  
**I want to** バーチャルランニングの体験をmp4動画ファイルとしてダウンロードしたい  
**So that** 「走った証拠」を保存したり、SNSで共有できる

**Priority**: Should Have (Phase 2)  
**Personas**: 佐藤美咲（SNS共有）、山田大輔（ネタ共有）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: バーチャルランニングが完了した  
   When: ユーザーが「動画を保存」ボタンを押す  
   Then: ランニング体験が動画ファイル（mp4）として生成・ダウンロードされる

**Supplementary Checklist:**
- ✓ 動画にはStreet View映像 + カウンター表示が含まれる
- ✓ 動画の長さは実際のランニング体験時間（早送りオプションあり）
- ✓ サーバーサイドで動画生成処理を行う
- ✓ 生成中はプログレスバーを表示

---

### US-013: 手振りアニメーション

**As a** より臨場感のある体験をしたいユーザー  
**I want to** 走行中に画面端に手を振っているアニメーションが表示されてほしい  
**So that** 一人称視点で走っている感覚がさらに強まる

**Priority**: Should Have (Phase 2)  
**Personas**: 田中健太（没入感）、佐藤美咲（リアルさ）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: バーチャルランニングが進行中  
   When: Street View画像が表示されている  
   Then: 画面下部に手を振るアニメーション（イラスト/GIF）がオーバーレイ表示される

**Supplementary Checklist:**
- ✓ アニメーションはStreet View画像を大きく遮らない
- ✓ 手振りのリズムはランニングペースに同期
- ✓ ON/OFF切り替え可能（好みに応じて非表示にできる）

---

### US-014: マップ上のコース履歴表示

**As a** 走った（風の）記録を振り返りたいユーザー  
**I want to** 過去に走ったコースをマップ上で一覧表示したい  
**So that** 「こんなに走った（風）」という達成感を視覚的に得られる

**Priority**: Should Have (Phase 2)  
**Personas**: 田中健太（コレクション）、山田大輔（記録遊び）

#### Acceptance Criteria

**Main Flow (Given-When-Then):**

1. Given: 過去にバーチャルランニングを完了している  
   When: ユーザーが「走行履歴」画面を開く  
   Then: 過去のコースがマップ上にライン表示される

**Supplementary Checklist:**
- ✓ 各コースは日付・距離・時間とともに表示
- ✓ コースをタップすると詳細（距離、カロリー、日時）が表示される
- ✓ 累積走行距離の合計が表示される
- ✓ 走行履歴はローカルストレージに保存（MVP時点ではアカウント不要）
